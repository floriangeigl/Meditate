在 geigl.online，我很重视你的隐私。本隐私政策说明，当你在 Garmin 设备上使用我的[冥想应用](/meditate_app/)时，我如何收集、使用和保护你的个人信息。

本文是译文，具有约束力的是英文版本。

**1. 我收集的信息**

应用本身不会连接互联网。所有网络请求都由配对手机上的 Garmin Connect 应用发出，因此，接收请求的每台服务器都能在连接层面看到你手机的公网 IP 地址。

使用我的冥想应用时，我可能会自动收集某些信息。每次保存练习后，应用会发送一条分析事件，其中包括：
* [Garmin 唯一标识符](https://developer.garmin.com/connect-iq/api-docs/Toybox/System/DeviceSettings.html#uniqueIdentifier-var)，每个应用与设备的组合都有一个独有的标识符
* 你的 IP 地址，按下文所述在手表上进行匿名化处理；Google Analytics 据此推算你的大致位置（国家、地区和城市）。如果查询失败，则不包含此项
* 基本练习数据：练习时长和结束时间
* 应用版本、Connect IQ API 版本、固件版本和系统语言
* 设备型号（Garmin 零件编号）、屏幕分辨率和操作系统
* 根据练习结束时间生成的练习标识符
* 应用内的使用行为
* 如果你是开发者，可以[在这里](https://github.com/floriangeigl/Meditate/tree/main/Meditate/source/com)查看相关源代码

事件会暂存在手表上，最多保存10条、最长保留71小时。手机可以连接后，这些事件会一并发送。事件不包含心率、HRV、压力、呼吸频率、活动名称、练习设置或任何其他健康或活动数据。

我使用 Google Analytics 来了解用户如何使用我的应用。Google 能在连接层面看到你手机的 IP 地址，也可能按照其[隐私政策](https://policies.google.com/privacy)所述收集其他技术数据。

为查询你手机的 IP 地址，应用自2026年10月起使用 GeoJS。每次尝试发送数据时，应用最多向 `https://get.geojs.io/v1/ip.json` 发出一次请求。发送尝试会发生在每次保存练习后，以及应用启动时仍有未发送事件等待发送的情况下。响应只包含你手机的公网 IP 地址；GeoJS 能在连接层面看到完整的 IP 地址。应用在手表上对 IP 地址进行匿名化处理后才会使用：对于 IPv4，将最后一段设为0（例如 203.0.113.0）；对于 IPv6，只保留前三段（/48）。完整的 IP 地址不会被存储或转发。GeoJS 声明，它不保留访问日志，只保留错误日志，并受澳大利亚《1988年隐私法》约束。详情请参阅 [GeoJS 隐私政策](https://www.geojs.io/privacy/)。

2026年10月之前，应用使用的是 ipapi.co：ipapi.co 能看到你手机的完整 IP 地址，而应用只会将其返回的国家、地区和城市发送给 Google Analytics，不会发送 IP 地址。详情请参阅 [ipapi.co 隐私政策](https://ipapi.co/privacy/)。

如果你上个月冥想至少15分钟，并且手机已连接，应用每月最多会在你的手机上打开一次我的[赞助页面](/tipme/)。链接中包含上个月的冥想分钟数（向上取整为整数），作为参数 `meditate-minutes`，另外还包含 `utm_source=meditate_app`、`utm_medium=garmin_watch` 和 `utm_campaign=tip`。由于赞助页面是我网站的一部分，网站使用的 Google Analytics（见下文）会记录包含这些参数的页面地址。

应用中还隐藏着一个供我开发时使用的云备份工具。它不在应用的常规菜单中，只能通过长按“关于”页面进入。只有你亲自在那里启动备份时，应用才会将应用设置、你保存的练习、每月冥想分钟数，以及应用学到的练习习惯上传到由 Google 运营的 [Firebase](https://firebase.google.com/support/privacy) Realtime Database。练习习惯信息最多涵盖过去90天内最近保存的100次练习：每次是哪种练习、开始日期和时间、时长（分钟），以及在开始前一小时内你完成了哪次练习（如有）。这些数据存储在上文所述的同一个 Garmin 唯一标识符下。应用不会自动向 Firebase 发送任何内容。除了赞助页面和此项备份，你每月的冥想分钟数只保留在手表上；除了此项备份，应用学到的练习习惯也只保留在手表上。

我的网站（包括赞助页面）使用 Google Analytics 来了解访问者如何使用网站。Google 信号功能和广告个性化功能均已关闭。

我使用 Cloudflare 作为内容分发网络（CDN）和安全服务提供商，以确保网站内容能够快速、安全地送达。当你访问我的网站时，请求会经过 Cloudflare 的服务器。出于安全和性能方面的需要，Cloudflare 可能会暂时记录你的 IP 地址和其他技术信息。Cloudflare 代表我处理数据，不会将这些数据用于其他目的。详情请参阅 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)。

我使用 jsDelivr 或 CDNJS 等公共内容分发网络（CDN）来加载 jQuery 和 Bootstrap 等静态资源。这些 CDN 可能会暂时记录你的 IP 地址等技术信息，以便高效地提供内容。这些信息不会用于跟踪或分析。

**2. 我如何使用你的信息**

我收集并使用这些信息，以便：
* 分析和改进应用的性能与易用性
* 了解用户如何使用应用
* 改善你的整体使用体验

我结合你的大致位置（国家、地区和城市）与系统语言，用于：
* 决定保留、维护或新增哪些应用语言版本
* 调整赞助页面，例如提供的货币和付款方式
* 决定在哪些国家及应用商店市场推广应用
* 了解哪些隐私法律适用于我的用户
* 识别并过滤虚假的分析流量，这类流量往往来自不常见的国家，或集中在个别地点附近
* 了解人们在当地一天中的什么时间冥想，这需要知道他们所在的时区
* 识别季节性的使用规律，例如北半球与南半球之间的差异

根据《通用数据保护条例》（GDPR），处理这些数据的法律依据是：
* 应用分析，包括通过 GeoJS 查询 IP 地址（2026年10月之前：通过 ipapi.co 查询位置）：我了解应用使用情况并改进应用的合法利益（GDPR 第6条第1款(f)项）。应用没有关闭分析功能的设置；你可以随时通过电子邮件提出反对（见第5节）。
* 赞助页面：我请求用户自愿支持应用的合法利益（GDPR 第6条第1款(f)项）。
* 网站分析：你通过我网站上的 Cookie 横幅给予的同意（GDPR 第6条第1款(a)项），你可以随时撤回。
* 云备份：你启动备份时主动提出的请求（GDPR 第6条第1款(b)项）。

我不会对你作出具有法律效力或类似重大影响的自动化决定（GDPR 第22条）。

**3. 数据共享**

我不会为营销目的向第三方出售或共享你的个人信息。上述分析事件会发送至 Google Analytics；IP 地址查询由 GeoJS 完成（2026年10月之前：ipapi.co）；你自行启动的备份则存储在 Firebase 中。

**4. 数据保留**

我不会将分析数据保留超过必要的时间。Google Analytics 的数据保留期限（应用和网站）目前设为14个月，以便了解一年中的使用趋势。GeoJS 声明，它不保留访问日志，只保留错误日志。ipapi.co（2026年10月之前使用）会在有限时间内保留请求日志，具体见其[隐私政策](https://ipapi.co/privacy/)。Firebase 中的备份不会自动删除；它们会一直保留，直到你要求我删除。

根据你所在的地区，你可能有权：

* 撤回你对数据处理的同意
* 反对基于我的合法利益进行的数据处理，包括应用分析

如需行使这些权利，请发送电子邮件至 florian.geigl+privacy@gmail.com 与我联系。

**6. 数据安全**

我采取适当措施，保护你的数据免遭未经授权的访问、修改、披露或销毁。

**7. 国际用户**

我依据《通用数据保护条例》（GDPR）处理你的数据。我使用的部分服务会在美国处理数据：
* Google（Google Analytics、Firebase）和 Cloudflare 已获得“欧盟-美国数据隐私框架”认证。
* ipapi.co（2026年10月之前使用）由 Kloudend, Inc.（美国）运营。根据其隐私政策，这些数据传输受标准合同条款约束。

GeoJS 受澳大利亚《1988年隐私法》约束。

应用会先在你的手表上对 IP 地址进行匿名化处理，然后才将其发送给 Google Analytics。
