geigl.online은 여러분의 개인정보를 중요하게 생각합니다. 이 개인정보 처리방침은 Garmin 기기에서 제 [명상 앱](/meditate_app/)을 사용할 때 개인정보를 어떻게 수집, 이용, 보호하는지 설명합니다.

이 문서는 번역본이며, 영어 원문이 법적 효력을 갖습니다.

**1. 수집하는 정보**

앱은 자체적으로 인터넷에 연결하지 않습니다. 모든 네트워크 요청은 페어링된 휴대전화의 Garmin Connect 앱을 통해 이루어지므로, 요청을 받는 모든 서버는 연결 과정에서 휴대전화의 공인 IP 주소를 볼 수 있습니다.

제 명상 앱을 사용하면 특정 정보가 자동으로 수집될 수 있습니다. 저장된 세션이 끝날 때마다 앱은 다음 정보가 포함된 분석 이벤트 하나를 전송합니다.
* 앱과 기기별로 고유한 [Garmin 고유 식별자](https://developer.garmin.com/connect-iq/api-docs/Toybox/System/DeviceSettings.html#uniqueIdentifier-var)
* 아래 설명한 방식으로 시계에서 익명화한 IP 주소. Google Analytics는 이 주소를 바탕으로 대략적인 위치(국가, 지역, 도시)를 추정합니다. 조회에 실패하면 이 정보는 포함되지 않습니다
* 기본 세션 정보: 세션 길이와 세션 종료 시각
* 앱 버전, Connect IQ API 버전, 펌웨어 버전 및 시스템 언어
* 기기 유형(Garmin 부품 번호), 화면 해상도 및 운영체제
* 세션 종료 시각을 기반으로 한 세션 식별자
* 앱 내 사용 패턴
* 개발자라면 관련 소스 코드를 [여기](https://github.com/floriangeigl/Meditate/tree/main/Meditate/source/com)에서 확인할 수 있습니다

이벤트는 휴대전화에 연결할 수 있을 때까지 시계에 보관되며(최대 10개, 최대 71시간), 연결되면 한꺼번에 전송됩니다. 이벤트에는 심박수, HRV, 스트레스, 호흡, 활동 이름, 세션 설정 또는 그 밖의 건강·활동 데이터가 포함되지 않습니다.

저는 이용자가 앱을 어떻게 사용하는지 이해하기 위해 Google Analytics를 사용합니다. Google은 연결 과정에서 휴대전화의 IP 주소를 볼 수 있으며, [개인정보 처리방침](https://policies.google.com/privacy)에 설명된 추가 기술 데이터를 수집할 수 있습니다.

앱은 휴대전화의 IP 주소를 조회하기 위해 2026년 10월부터 GeoJS를 사용합니다. 저장된 세션이 끝날 때와 전송되지 않은 이벤트가 남아 있는 상태에서 앱을 시작할 때, 전송 시도당 최대 한 번 `https://get.geojs.io/v1/ip.json`으로 요청을 보냅니다. 응답에는 휴대전화의 공인 IP 주소만 포함되며, GeoJS는 연결 과정에서 전체 IP 주소를 볼 수 있습니다. 앱은 이 주소를 사용하기 전에 시계에서 익명화합니다. IPv4 주소는 마지막 블록을 0으로 바꾸고(예: 203.0.113.0), IPv6 주소는 처음 세 블록(/48)만 남깁니다. 전체 IP 주소는 저장하거나 다른 곳으로 전달하지 않습니다. GeoJS는 접속 로그를 보관하지 않고 오류 로그만 보관하며, 호주의 1988년 개인정보 보호법(Privacy Act 1988)을 적용받는다고 밝힙니다. 자세한 내용은 [GeoJS 개인정보 처리방침](https://www.geojs.io/privacy/)을 확인해 주세요.

2026년 10월 이전에는 앱이 ipapi.co를 대신 사용했습니다. ipapi.co는 휴대전화의 전체 IP 주소를 볼 수 있었으며, 앱은 ipapi.co가 반환한 국가, 지역, 도시 정보만 Google Analytics에 전송하고 IP 주소는 전송하지 않았습니다. 자세한 내용은 [ipapi.co 개인정보 처리방침](https://ipapi.co/privacy/)을 확인해 주세요.

한 달 동안 명상을 15분 이상 했고 휴대전화가 연결되어 있을 때에만, 앱은 한 달에 최대 한 번 휴대전화에서 제 [후원 페이지](/tipme/)를 엽니다. 링크에는 지난달 명상 시간(분 단위로 올림)이 `meditate-minutes` 매개변수로 포함되며, `utm_source=meditate_app`, `utm_medium=garmin_watch`, `utm_campaign=tip`도 포함됩니다. 후원 페이지는 제 웹사이트의 일부이므로, 웹사이트의 Google Analytics(아래 참조)는 이 매개변수가 포함된 페이지 주소를 기록합니다.

앱에는 제가 개발에 사용하는 숨겨진 클라우드 백업 도구도 있습니다. 일반 앱 메뉴에는 나타나지 않으며, 정보 화면을 길게 눌러야 접근할 수 있습니다. 해당 화면에서 직접 백업을 실행할 때에만 앱 설정, 저장된 세션, 월별 명상 시간, 학습된 루틴이 Google이 운영하는 [Firebase](https://firebase.google.com/support/privacy) Realtime Database에 업로드됩니다. 학습된 루틴에는 최근 90일 이내에 저장된 세션 중 최대 100개에 대해 어떤 세션이었는지, 시작 날짜와 시각, 길이(분), 그리고 해당 세션을 시작하기 전 최대 한 시간 이내에 완료한 세션이 있다면 어떤 세션이었는지가 포함됩니다. 이 데이터는 위에서 설명한 동일한 Garmin 고유 식별자 아래에 저장됩니다. Firebase로 자동 전송되는 정보는 없습니다. 후원 페이지와 이 백업을 제외하면 월별 명상 시간은 시계에만 남으며, 이 백업을 제외하면 학습된 루틴도 시계에만 남습니다.

후원 페이지를 포함한 제 웹사이트는 방문자의 이용 방식을 이해하기 위해 Google Analytics를 사용합니다. Google 신호 데이터와 광고 개인 최적화 기능은 꺼져 있습니다.

저는 웹사이트를 빠르고 안전하게 제공하기 위해 콘텐츠 전송 네트워크(CDN) 및 보안 서비스 제공업체로 Cloudflare를 사용합니다. 웹사이트에 접속하면 요청이 Cloudflare 서버를 거치며, Cloudflare는 보안 및 성능을 위해 IP 주소와 기타 기술 정보를 일시적으로 기록할 수 있습니다. Cloudflare는 저를 대신해 데이터를 처리하며, 이 데이터를 다른 목적으로 사용하지 않습니다. 자세한 내용은 [Cloudflare 개인정보 처리방침](https://www.cloudflare.com/privacypolicy/)을 확인해 주세요.

저는 jQuery와 Bootstrap 같은 정적 리소스를 불러오기 위해 jsDelivr나 CDNJS 같은 공개 콘텐츠 전송 네트워크(CDN)를 사용합니다. 이러한 CDN은 콘텐츠를 효율적으로 제공하기 위해 IP 주소 등의 기술 정보를 일시적으로 기록할 수 있습니다. 이 정보는 이용자 추적이나 분석에 사용되지 않습니다.

**2. 정보 이용 방법**

저는 이 정보를 다음 목적으로 수집하고 이용합니다.
* 앱의 성능과 사용 편의성 분석 및 개선
* 이용자의 앱 사용 방식 파악
* 전반적인 이용 경험 개선

저는 대략적인 위치(국가, 지역, 도시)와 시스템 언어를 함께 사용해 다음 사항을 판단합니다.
* 앱에서 어떤 번역을 유지, 관리하거나 추가할지
* 후원 페이지의 통화와 결제 수단 등을 어떻게 조정할지
* 어떤 국가와 앱 스토어 시장에서 앱을 홍보할지
* 이용자에게 어떤 개인정보 보호법이 적용되는지
* 비정상적인 국가나 특정 위치 주변에 집중되는 경우가 많은 허위 분석 트래픽을 어떻게 탐지하고 걸러낼지
* 이용자의 시간대를 바탕으로 현지 시간으로 하루 중 언제 명상하는지
* 북반구와 남반구의 차이 같은 계절별 이용 패턴

일반 개인정보 보호 규정(GDPR)에 따른 법적 근거는 다음과 같습니다.
* GeoJS를 통한 IP 조회를 포함한 앱 분석(2026년 10월 이전에는 ipapi.co를 통한 위치 조회): 앱의 사용 방식을 이해하고 개선하려는 저의 정당한 이익(Art. 6(1)(f) GDPR). 앱에는 분석 기능을 끄는 설정이 없지만, 언제든 이메일로 이의를 제기할 수 있습니다(5항 참조).
* 후원 페이지: 앱에 대한 자발적인 후원을 요청하려는 저의 정당한 이익(Art. 6(1)(f) GDPR).
* 웹사이트 분석: 웹사이트의 쿠키 배너를 통해 제공한 동의(Art. 6(1)(a) GDPR). 동의는 언제든 철회할 수 있습니다.
* 클라우드 백업: 백업을 시작할 때 이용자가 직접 하는 요청(Art. 6(1)(b) GDPR).

저는 이용자에게 법적 효과 또는 이와 비슷하게 중대한 영향을 미치는 자동화된 결정을 내리지 않습니다(Art. 22 GDPR).

**3. 데이터 공유**

저는 마케팅 목적으로 개인정보를 제3자에게 판매하거나 공유하지 않습니다. 위에서 설명한 분석 이벤트는 Google Analytics로 전송되고, IP 조회는 GeoJS(2026년 10월 이전에는 ipapi.co)를 통해 이루어지며, 이용자가 직접 실행한 백업은 Firebase에 저장됩니다.

**4. 데이터 보유 기간**

저는 분석 데이터를 필요한 기간보다 오래 보관하지 않습니다. 연간 이용 추세를 파악하기 위해 Google Analytics의 데이터 보유 기간(앱 및 웹사이트)은 현재 14개월로 설정되어 있습니다. GeoJS는 접속 로그를 보관하지 않고 오류 로그만 보관한다고 밝힙니다. 2026년 10월 이전에 사용한 ipapi.co는 [개인정보 처리방침](https://ipapi.co/privacy/)에 설명된 대로 요청 로그를 제한된 기간 동안 보관합니다. Firebase의 백업은 자동으로 삭제되지 않으며, 이용자가 저에게 삭제를 요청할 때까지 보관됩니다.
